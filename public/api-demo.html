Prueba de consumo externo — API REST de K'in Solar Guatemala

Esta página es un archivo HTML autocontenido, sin backend propio y sin ninguna dependencia del proyecto Laravel. Solo usa fetch() de JavaScript para consultar la API pública en vivo, igual que lo haría cualquier sistema externo del MINEM, una municipalidad o una ONG. Se puede abrir directamente como archivo local (doble clic, sin servidor) y seguirá funcionando.

Por qué esto es prueba real de consumo externo: el servidor responde con la cabecera Access-Control-Allow-Origin: *, así que cualquier origen — incluyendo null (un archivo abierto localmente) — puede leer la respuesta. No se envía ninguna cookie de sesión ni token: la API es pública y de solo lectura.
