# Registro de Evidencias Visuales

Este directorio almacena la evidencia visual exigida por la rúbrica de evaluación (Criterio 2: Uso de IA y Criterio 3: UI/UX):

### Ecosistema y Servidores MCP (Model Context Protocol)
- `mcp-01.png`: Lista de servidores MCP conectados en el entorno de desarrollo (`filesystem`, `mysql`, `github`).
- `mcp-02.png`: Ejecución en vivo de herramienta MCP `mysql.query` para auditoría del catálogo departamental y paneles solares.
- `mcp-03.png`: Ejecución en vivo de herramienta MCP `github.list_pull_requests` verificando el flujo de ramas y merges en `master`.
- `evidencia-mcp-server-propio.png`: Ejecución en vivo del Servidor MCP Propio (`mcp-server/`) respondiendo peticiones de lectura y escritura en producción.

### Funcionalidades Core y Rúbrica de Evaluación
- `evidencia-proyecciones-sma-sf.png`: Validación del modelo predictivo SMA-SF contrastando proyecciones con valores reales (RF-15).
- `evidencia-alertas-deficit.png`: Detección automática y resolución de alertas por déficit energético ≥ 20% (RF-14).
- `evidencia-reportes-departamentales.png`: Consolidado de los 22 departamentos con factor CO₂ (0.40) y exportación a CSV con BOM UTF-8 (RF-12).

### Experiencia de Usuario y Plataforma Web / Móvil (K'in Solar Guatemala)
- `kin-solar-dashboard-desktop.png`: Vista general del Dashboard Nacional en modo oscuro en pantalla de escritorio.
- `kin-solar-dashboard-mobile.png`: Vista móvil compacta sin scroll horizontal.
- `kin-solar-map-mobile.png`: Mapa interactivo móvil contenido en una pantalla (cero scroll) con leyendas y contadores solares visibles.
